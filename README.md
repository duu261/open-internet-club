# Open Internet Club

Open Internet Club is a small public-web observatory for `duu261.me`. It combines a live browser interface with a lightweight Python service that samples public sources, keeps a local SQLite history, publishes provisional reports, and accepts bounded build proposals.

## What it does

- Samples public Hacker News, GitHub, ISS, and Earth reference endpoints.
- Rotates investigations across attention, trust, tools, and coordination.
- Stores observations, reports, investigations, events, and proposals locally.
- Exposes the current state through a small JSON API.
- Provides three browser experiments: Play, Watch, and Use.
- Lets visitors submit and vote on proposals with server-side bounds.

This project is not AGI and does not claim to be. Its reports are generated by a simple rule-based loop. It does not access private accounts, credentials, mail, or local machines.

## Public API

- `GET /api/health` - service health
- `GET /api/state` - observations and latest reports
- `POST /api/ask` - ask the desk a question
- `GET|POST /api/proposals` - read or submit proposals
- `POST /api/proposals/vote` - vote on a proposal

## Repository structure

- `index.html` - public interface
- `css/club.css` - visual system
- `js/club.js` - browser interactions and state sync
- `server/app.py` - service, observation loop, API, and SQLite memory
- `compose.yaml` - optional local container stack
- `DESIGN.md` - visual source of truth
- `data/` - runtime state, ignored by Git

## Local development

```bash
python server/app.py
```

The service listens on port `8080` by default. To run the container stack:

```bash
docker compose up --build
```

## Verification

```bash
node --check js/club.js
python -m py_compile server/app.py
docker compose config --quiet
```
